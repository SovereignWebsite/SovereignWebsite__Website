The open pattern

Websites built by agents and owned by the people they are for.

Anyone can use the sovereign agentic website pattern without paying us, the way anyone can install WordPress. That is the point: a site you own should not depend on us existing.

Go to sovereignwebsite.org

sovereignwebsite.org holds the principles and the open pattern, as wordpress.org is to WordPress; sovereignwebsite.ai, this site, is for the hosted service.

What the pattern is

A sovereign agentic website is a repository the owner controls. It holds:

  • The site, as plain files

    Static files, built once and served as they are.

  • Its content and its schema

    The structure of the site as files in open formats, not a format a vendor chose.

  • Instructions for the agents

    What the site is, how to change it, and what not to touch.

  • The behaviour policy

    What any agent working on the site may and may not do.

  • Checks and a deploy

    Checks that run before anything goes live, and a deploy that runs on any host.

Agentic is how the site is built and changed. Sovereign is what it is, whoever built it: the seven principles hold for a site made by hand, too.

Source: Sovereign Agentic Website and What is a sovereign website.

An open stack, layer by layer

Each layer is open and builds on the one below.

  1. Sovereign WebsiteA website built by agents and owned by the person it is for: AgentiCCells' first mass-market product, one of its cells.
  2. AgentiCCellsAgentic teams, cells, installed for a customer, each with a job, a deliverable and a behaviour policy. For larger agentic teams, see agenticcells.ai.
  3. RiskMandateThe governance: behaviour policies that say what agents may and may not do, and the gap between what they can reach and what they were asked to do.
  4. SGitThe base: encrypted, versioned vaults as an open standard, like git, where work and its history live.

Source: Designing sovereignwebsite.ai.

Others can build on it

Because it is open, the pattern is also a base for other businesses: partners who sell and support it in their own country and language, agencies, newsrooms, councils. And a partner who takes the open code and does it alone is still a win: one more team running the technology, and one more place where agent behaviour policies are used for real. See partners.

The code and the policies are open source, so even we cannot lock anyone in.

Source: Partners sell, we build, Sovereignty you can move and No lock-in.

Where it stands

  • The domains sovereignwebsite.ai, sovereignwebsite.com and sovereignwebsite.site, and the SovereignWebsite organisation on GitHub, were set up on 19 November 2026; sovereignwebsite.org was registered the same day, to hold the principles.
  • The organisation will hold the open pattern; the pattern's own repository does not exist yet.
  • The site factory and the agent team that make these sites already exist, and make sites under an earlier name, the AgentiCCells website cell.
