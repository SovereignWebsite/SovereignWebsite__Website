Why level 4, and not 5

Read against the self-check: the words and the whole site are files in a public repository (questions 1 and 2); nothing in them depends on a part we do not control (question 3); any host that serves plain files could serve them without changes, and the domains were registered for the SovereignWebsite team on 19 November 2026 (question 4).

Question 5 is a no. Each site is deployed today to one host, GitHub Pages. The pipeline that deploys the same commit to many hosts does not exist yet, so none of these sites is proven by having moved. When that pipeline exists, sovereignwebsite.ai is meant to be its first proof.

One honest note: the deploy step itself is a GitHub Actions workflow, which is GitHub's own. The files need no change to move; another host would need its own deploy step.

Source: Designing sovereignwebsite.ai, What is a sovereign website and Sovereign Agentic Website, and the organisation's own factory repository.
